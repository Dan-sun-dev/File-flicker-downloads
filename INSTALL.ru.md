# Установка File flicker

Выберите установщик для своего компьютера в разделе **Releases** на странице скачивания. Отдельно устанавливать Python, FFmpeg или модели нейросетей не требуется: необходимые компоненты входят в комплект. Для обработки файлов интернет не нужен.

## Windows

Требуется **Windows 11, 64-разрядная система x64**.

1. Скачайте установщик File flicker с расширением `.exe`.
2. Если File flicker уже открыт, дождитесь завершения обработки и закройте приложение.
3. Запустите установщик и следуйте его шагам.
4. По желанию оставьте включённым пункт **«Добавить File flicker в меню Проводника»**. При его установке может появиться запрос администратора.
5. Завершите установку и запустите File flicker из меню «Пуск» или созданного ярлыка.

### Меню Проводника

Если интеграция установлена, выберите один или несколько файлов одного типа, нажмите правой кнопкой мыши и выберите **File flicker**.

Если пункта нет, откройте приложение и нажмите **«Меню Проводника» → «Добавить в меню Windows 11…»**. После установки закройте и снова откройте окно Проводника.

В текущей тестовой Windows-сборке интеграция использует локальный сертификат подписи. Установщик может запросить разрешение на добавление этого сертификата. Интеграция необязательна: без неё приложение можно запускать обычным ярлыком.

### Предупреждение Windows при первом запуске

У нового приложения может ещё не быть репутации Microsoft SmartScreen. Если появился экран защиты, проверьте, что файл скачан со страницы нашего релиза. Если вы доверяете этому файлу и Windows предлагает такой вариант, раскройте дополнительные сведения и выберите **«Выполнить в любом случае»**.

Сведения о проверке репутации: [документация Microsoft](https://learn.microsoft.com/ru-ru/windows/apps/package-and-deploy/smartscreen-reputation).

## macOS

Целевая минимальная система — **macOS 12 Monterey**. Перед скачиванием сверьтесь с описанием конкретного релиза: первые сборки для Mac являются тестовыми.

### Как выбрать версию

Откройте **меню Apple → «Об этом Mac»**.

- Если указан **чип Apple**, скачайте **Apple Silicon / arm64**.
- Если указан **процессор Intel**, скачайте **Intel / x86_64**.

Например, iMac 2015 с Intel Core i5 и macOS 12.7.6 нужен вариант **Intel**. Год выпуска сам по себе не определяет нужный установщик — ориентируйтесь на процессор.

### Установка

1. Скачайте подходящий файл `.dmg`.
2. Откройте его двойным щелчком.
3. Перетащите **File flicker.app** в папку **«Программы» / Applications**.
4. Откройте папку «Программы» и запустите File flicker оттуда.
5. После копирования извлеките образ File flicker в Finder.

### Если macOS не разрешает первый запуск

Текущая тестовая версия не нотарифицирована Apple, поэтому система может показать предупреждение о невозможности проверить разработчика.

Если вы доверяете файлу, скачанному со страницы нашего релиза, сначала попробуйте открыть приложение, затем разрешите его открытие в настройках безопасности:

- **macOS Monterey:** «Системные настройки» → «Защита и безопасность» → «Основные».
- **Более новые macOS:** «Системные настройки» → «Конфиденциальность и безопасность».

Найдите сообщение о File flicker и кнопку разрешения открытия, затем подтвердите запуск. Название кнопки зависит от версии macOS. При сообщении об обнаруженном вредоносном ПО или повреждении приложения обратитесь к разработчику — это другое предупреждение.

Подробности: [инструкция Apple о безопасном открытии приложений](https://support.apple.com/ru-ru/102445).

### Быстрое действие Finder

Откройте **«Меню Finder»** в приложении и выберите добавление быстрого действия. Затем в Finder выделите файлы одного типа и откройте **«Быстрые действия» → File flicker**. Если действие не отображается, проверьте его включение в настройках расширений macOS.

Интеграция Finder в тестовой версии требует проверки на реальном Mac. Добавление файлов кнопкой и перетаскиванием доступно независимо от неё.

## Первый результат

1. Добавьте изображение, видео, GIF или шрифт. Можно выбрать несколько файлов одного типа.
2. Выберите доступную операцию: сжатие, конвертацию или редактор изображений.
3. Для конвертации укажите формат результата. При необходимости измените дополнительные параметры.
4. Оставьте включённым **«Сохранить копию»**, чтобы сохранить оригинал.
5. Нажмите **«Сжать»**, **«Конвертировать»** или **«Сохранить»** и дождитесь завершения.

Результат сохраняется рядом с исходным файлом. В папке должно быть достаточно свободного места и разрешение на запись. Если отключить «Сохранить копию», приложение заменит исходник после успешной обработки; при смене формата изменится и расширение файла.

## Обновление и удаление

**Windows:** закройте File flicker и запустите новый установщик. Для удаления используйте список установленных приложений в параметрах Windows.

**Mac:** закройте приложение и замените File flicker.app в папке «Программы» новой версией. Для удаления сначала уберите быстрое действие через «Меню Finder», если добавляли его, затем переместите приложение в Корзину.

Созданные изображения, видео, GIF и шрифты хранятся отдельно от приложения и не удаляются вместе с ним.
