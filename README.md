# File flicker

**Сжимайте файлы, меняйте форматы и подготавливайте изображения в одном приложении.**

File flicker — приложение для работы с изображениями, видео, GIF и шрифтами. Уменьшайте размер файлов перед отправкой, конвертируйте видео в GIF, удаляйте фон и готовьте шрифты для сайта. Обработка выполняется на вашем компьютере: файлы не отправляются на сервер, аккаунт не нужен.

## Что умеет File flicker

### Изображения

- Сжимать изображения с настройкой силы сжатия.
- Конвертировать в JPG, PNG, WebP, AVIF, TIFF и BMP.
- Обрезать, поворачивать, отражать и изменять размеры.
- Удалять фон с помощью нейросети и сохранять результат с прозрачностью.
- Увеличивать изображения в 2 или 4 раза с помощью нейросети.
- Удалять метаданные.

### Видео и GIF

- Сжимать видео и подбирать параметры под указанный максимальный размер файла.
- Конвертировать в MP4, MOV, MKV и WebM.
- Создавать GIF из видео с настройками частоты кадров и ширины.
- Сжимать существующие анимированные GIF.

### Шрифты

- Конвертировать между TTF, OTF, WOFF и WOFF2.
- Обрабатывать несколько шрифтов за один запуск.

Приложение определяет тип выбранных файлов и показывает подходящие инструменты. Для шрифтов доступна конвертация, для видео — сжатие и конвертация, для изображений — также редактор.

## Удобно в повседневной работе

- Добавляйте файлы кнопкой или перетаскиванием.
- Обрабатывайте несколько файлов одного типа последовательно.
- Запускайте приложение из меню Проводника Windows или через Finder на Mac.
- Сравнивайте исходный и итоговый размер файла. Для видео до обработки показывается приблизительная оценка.
- Сохраняйте результат отдельной копией, чтобы оставить оригинал.
- Отменяйте текущую обработку и возвращайтесь к предыдущим действиям в редакторе.

## Что полезно знать

Видео, изображения и шрифты обрабатываются отдельными наборами. Если добавить разные типы одновременно, приложение объяснит проблему. Чтобы перейти к другому типу, очистите список.

Видео обрабатывается без обрезки и монтажа. Основной поддерживаемый режим — SDR; HDR пока не поддерживается. При конвертации переносится первая аудиодорожка, дополнительные дорожки и субтитры не переносятся. GIF сохраняется без звука.

Сильное сжатие уменьшает качество. Конвертация в формат с потерями даже на максимальном качестве не гарантирует сохранение пикселей без изменений. Нейросетевое удаление фона может ошибаться на сложных контурах, прозрачных объектах и волосах.

Коллекции шрифтов TTC не поддерживаются. Для вариативных шрифтов преобразования с изменением типа контуров могут быть недоступны; приложение сообщит об этом.

В предварительной версии для Mac видео и нейросетевые операции обрабатываются на процессоре. Скорость зависит от компьютера, размеров файлов и выбранной операции.
